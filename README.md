# Basic Login Page Screen

A styled login form made with HTML and CSS.

## What it demonstrates
- Centering a form box with CSS
- Styling inputs and buttons
- Hover and focus transitions

## Features
- Username and password fields
- Login button with a hover effect
- UI only: there is no real login or backend

## Tech
- HTML, CSS

## How to run
Open `index.html` in your browser.
